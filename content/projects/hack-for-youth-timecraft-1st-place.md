## Overview

I built TimeCraft solo in six hours to help users think through priorities and schedule them directly into Google Calendar.

## Process

Flask handles Google authentication and API integration. A Groq Llama model generates structured action requests that the backend parses into calendar operations. JSON mode helped resolve unreliable output formatting.

## Result

Won first place at Hack For Youth. The prototype displays calendar events and supports conversational scheduling; voice input was a proposed next step.
