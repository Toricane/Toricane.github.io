## Overview

Scoped collects a complete job-search result table so it can be explored without repeatedly paging through SCOPE. Postings can be exported as CSV or JSON and reopened in the original portal.

## Process

The Firefox-first, Chrome-compatible extension keeps collection data in the browser. Packaged MiniLM semantic search runs locally in a worker, alongside literal search, organization and location filters, and offline geography assets.

## Result

Implemented collection, saved/applied views, export, and backup/restore. Collection reads result tables; it does not submit applications or read individual job descriptions. Store publication and Mozilla signing remain separate steps.
