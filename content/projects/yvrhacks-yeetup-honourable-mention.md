## Overview

I built yeetup solo for the theme of improving students’ lives. It offers a conversational way to discover events, inspired in part by buildspace’s earlier Sage interface.

## Process

Users can type or speak an event query. The Flask/Groq prototype searches its event repository and answers in natural language, with follow-up questions for more detail.

## Result

Received an Honourable Mention. Building solo made it possible to move quickly from concept to prototype, while limiting how many features I could finish.
